# Postman验收

（1）打开Postman，导入`CodeClinic.postman_collection.json`。

（2）按集合顺序运行请求，集合会验证注册、登录、验证码响应不泄露、核心业务接口，并自动保存登录凭证和错题编号。

（3）默认服务地址为`http://localhost:8080`，启动方式见项目根目录`README.md`。

（4）真实邮箱验证码不能由自动化脚本读取。配置发件邮箱后，请在页面输入已注册的真实邮箱，点击“发送验证码”，再前往收件箱查看。

本目录的`results/`由验收脚本生成，记录每个请求的HTTP状态和响应摘要。

（5）recovery-filter集合用于独立验收库：先运行功能准备集合建立acceptanceuser及第1题，停服后将该题设为status=1，再启动服务，运行此集合验证恢复和完整错误类型筛选。仅用于可丢弃数据。
（6）review-page集合要求同一临时用户共101题，编号1至101，第101题尚未复习；验证20条分页、末页、备注历史和重复提交保护。历史接口可传page、size逐页读取。不得在现有业务库直接建立这些固定编号的测试数据。
